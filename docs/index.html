DefiMemory

Le jeu de mémoire en 5 niveaux : mémorisez les cartes, puis retrouvez toutes les paires.

Comment jouer

Au début de chaque partie, toutes les cartes sont visibles quelques secondes puis se retournent. Touchez deux cartes : si elles sont identiques, elles restent ouvertes. Trouvez toutes les paires en un minimum de coups. Gagnez un niveau pour débloquer le suivant.

Questions fréquentes

Je n'entends pas le son. Vérifiez que l'icône du haut-parleur n'est pas barrée, que le volume est monté et, sur iPhone, que le bouton silencieux n'est pas activé.

Comment débloquer le niveau Maître ? Gagnez le niveau Expert (15 paires en moins de 2 min 30).

Ma progression a disparu. Elle est enregistrée sur le téléphone uniquement : elle est effacée si le jeu est désinstallé.
